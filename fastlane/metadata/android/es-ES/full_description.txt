Reqistry es inteligencia de APIs para ti — y para tus agentes de IA.

Descubre más de 3.500 APIs públicas de IA, herramientas para agentes, finanzas, meteorología, música, seguridad, productividad, juegos, salud, educación y mucho más. No solo encuentres APIs: evalúalas antes de desarrollar. Cada API muestra señales de confianza: salud observada en vivo por la plataforma, puntuación de confianza, requisitos de autenticación, precios y compatibilidad con HTTPS y CORS.

COMPARA, NO ADIVINES

Elige de 2 a 8 APIs y compara confianza, precios, velocidad y disponibilidad lado a lado, con evidencia en vivo.

SUPERVISA LO QUE PUBLICAS

Guarda APIs en listas de seguimiento con resúmenes diarios de salud y alertas cuando bajan las puntuaciones de confianza. El registro de cambios sigue eventos de salud, precios y confianza en todo el catálogo.

ORGANIZA Y CONTRIBUYE

Agrupa APIs en proyectos, sincroniza tus favoritos y propón nuevas APIs para ampliar el catálogo.

PENSADO PARA AGENTES DE IA

Crea claves de API para agentes en Ajustes y conecta tus agentes mediante MCP (Ajustes → MCP), para que consulten el mismo catálogo de confianza que tú ves.

Descubrimiento gratis, sin suscripciones. La app se financia con anuncios (banner y anuncios nativos claramente etiquetados). Tus opciones de privacidad publicitaria se recogen antes de cargar ningún anuncio (UMP de Google) y puedes revisarlas en Ajustes → Opciones de privacidad.
